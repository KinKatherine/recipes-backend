# 🥘 Сборник Рецептов (Backend Service)

## 📝 Описание Проекта

Сервис "**Сборник Рецептов**" — это бэкенд-система, предназначенная для хранения, управления и предоставления структурированных данных о кулинарных рецептах через **RESTful API**.

Проект решает проблему **структурированного хранения, быстрого поиска и безопасного доступа** к коллекции рецептов, обеспечивая полный цикл жизни данных (CRUD) для пользователей с разными уровнями доступа.

**Целевая аудитория:** Обычные пользователи, которым нужен удобный каталог рецептов, и профессиональные повара, желающие делиться своим контентом.

---

## 🛠️ Стек Используемых Технологий

Бэкенд-сервис построен на надежном стеке Java-технологий, ориентированном на производительность и безопасность.

| Категория | Технологии | Назначение |
| :--- | :--- | :--- |
| **Язык** | **Java** (JDK 21+) | Основной язык разработки. |
| **Фреймворк** | **Spring Boot** | Быстрая разработка и настройка REST-сервиса. |
| **База данных** | **PostgreSQL** | Надежное реляционное хранилище данных. |
| **ORM / JPA** | **Hibernate** | Управление взаимодействием с БД. |
| **Безопасность** | **Spring Security + JWT** | Аутентификация и авторизация пользователей. |
| **Сборщик** | **Maven** | Управление зависимостями проекта. |
| **Документация** | **Swagger / OpenAPI** | Интерактивная документация API. |

## 👥 Роли Пользователей и Права Доступа

Система имеет четкое разделение ролей, определяющее их разрешения (CRUD-операции).

### Роли и Разрешения (CRUD)

| Роль | Чтение (R) | Создание (C) | Обновление (U) | Удаление (D) | Дополнительные Действия |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Гость** | Просмотр рецептов/категорий, Поиск. | Регистрация. | - | - | - |
| **Авторизованный Пользователь** | Всё, что может Гость + Избранное. | **Рецепты** (на модерацию), Комментарии, Оценки. | Свои комментарии/оценки. | Свои комментарии/оценки. | Отправка рецепта на модерацию. |
| **Администратор** | Все данные. | Любой контент. | Любой контент. | Любой контент. | **Модерация** (Подтверждение/Отклонение). |

## 🚀 API Endpoints

Сервис предоставляет **RESTful API**. Все защищенные эндпоинты требуют передачи **JWT-токена** в заголовке `Authorization: Bearer <token>`.

### 1. Аутентификация (Authentication)

| Метод | Путь | Описание |
| :---: | :--- | :--- |
| **POST** | `/auth` | Регистрация нового пользователя и/или получение JWT-токена (Login/Register). |

### 2. Рецепты (Recipes Methods)

| Метод | Путь (v1) | Описание | Доступ |
| :---: | :--- | :--- | :--- |
| **GET** | `/api/v1/recipes` | Получение списка всех рецептов (с фильтрацией). | Гость / Авторизованный |
| **GET** | `/api/v1/recipes/{id}` | Получение конкретного рецепта по ID. | Гость / Авторизованный |
| **POST** | `/api/v1/recipes/create` | Создание нового рецепта (отправка на модерацию). | Авторизованный |
| **PUT** | `/api/v1/recipes/update/{id}` | Обновление существующего рецепта. | Автор / Администратор |
| **DELETE** | `/api/v1/recipes/delete/{id}` | Удаление рецепта. | Автор / Администратор |

### 3. Категории (Categories Methods)

| Метод | Путь (v1) | Описание | Доступ |
| :---: | :--- | :--- | :--- |
| **GET** | `/api/v1/categories` | Получение списка всех категорий. | Гость / Авторизованный |
| **GET** | `/api/v1/category/{id}/recipes` | Получение всех рецептов из указанной категории. | Гость / Авторизованный |
| **POST** | `/api/v1/categories/create` | Создание новой категории. | Администратор |
| **PUT** | `/api/v1/categories/update/{id}` | Обновление категории. | Администратор |
| **DELETE** | `/api/v1/categories/delete/{id}` | Удаление категории. | Администратор |
