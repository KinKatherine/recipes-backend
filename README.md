# 🥘 Сборник Рецептов (Backend Service)

## 📝 Описание Проекта

Сервис "**Сборник Рецептов**" — это бэкенд-система, предназначенная для хранения, управления и предоставления
структурированных данных о кулинарных рецептах через **RESTful API**.

Проект решает проблему **структурированного хранения, быстрого поиска и безопасного доступа** к коллекции рецептов,
обеспечивая полный цикл жизни данных (CRUD) для пользователей с разными уровнями доступа.

**Целевая аудитория:** Обычные пользователи, которым нужен удобный каталог рецептов, и профессиональные повара, желающие
делиться своим контентом.

## 🌐 Организация сетевого взаимодействия: Radmin VPN

Для обеспечения взаимодействия фронтенда и бэкенда, находящихся на разных физических машинах, мы используем **Radmin VPN**.

### 💡 Базовые принципы

**Radmin VPN** создает **виртуальную локальную сеть (VPN)**, объединяющую компьютеры участников команды. Это позволяет компьютерам обмениваться данными, используя **частные IP-адреса** (формата `26.x.x.x`), как если бы они находились в одной физической сети.

- **Виртуальный IP:** Каждый компьютер в сети Radmin получает уникальный IP-адрес формата `26.x.x.x`.
- **Прямое Обращение:** Клиент (React-приложение) обращается к серверу, используя именно **Radmin IP-адрес** машины разработчика бэкенда.

### 🛠️ Инструкция по настройке соединения

1.  **Установка Radmin VPN:** Установите Radmin VPN на машинах разработчика сервера и разработчика клиента.
2.  **Создание Сети (Разработчик Бэкенда):**
    - Создать новую сеть в Radmin VPN (задать имя и пароль).
3.  **Подключение к Сети (Разработчик Клиента):**
    - Подключиться к созданной сети, используя имя и пароль.
4.  **Определение Адреса Сервера:**
    - Разработчик бэкенда сообщает **свой Radmin IP-адрес** (адрес `26.x.x.x`, который виден в Radmin VPN) и **порт**, на котором запущен сервер (например, `8080`).
    - **Важно:** Бэкенд должен прослушивать **все интерфейсы** (0.0.0.0), чтобы принимать подключения не только с `localhost`.
5.  **Конфигурация Клиента:**
    - В коде React-приложения, для всех сетевых запросов, используется URL, состоящий из **Radmin IP-адреса** и **порта** сервера.

После выполнения этих шагов, клиент (фронтенд) и сервер (бэкенд) будут успешно взаимодействовать через виртуальную локальную сеть.

## 🚀 Деплой (Docker)

Для развертывания приложения используя Docker выполните следующие шаги.

### 1. Создание сети

Создаем изолированную сеть для общения контейнеров:

```bash
docker network create recipes-net
```

### 2. Запуск Базы Данных (PostgreSQL)

Запускаем контейнер с PostgreSQL и создаем том для сохранения данных:

```bash
docker run -d \
  --name recipes-db \
  --network recipes-net \
  -e POSTGRES_DB=recipes_db \
  -e POSTGRES_USER=postgres \
  -e POSTGRES_PASSWORD=your_strong_db_password \
  -v db_data:/var/lib/postgresql/data \
  postgres:17-alpine
```

### 3. Сборка Бэкенда

Находясь в корне проекта, собираем образ приложения:

```bash
docker build -t recipes-backend .
```

### 4. Запуск Бэкенда

Запускаем приложение, передавая все необходимые переменные окружения:

```bash
docker run -d \
  --name recipes-backend-app \
  --network recipes-net \
  -p 8080:8080 \
  -e RECIPES_DATASOURCE_URL=jdbc:postgresql://recipes-db:5432/recipes_db \
  -e RECIPES_DATABASE_NAME=postgres \
  -e RECIPES_DATABASE_PASSWORD=your_strong_db_password \
  -e RECIPES_USER_PASSWORD=admin_password \
  -e RECIPES_JWT_SECRET=your_jwt_secret_key_change_it \
  -e RECIPES_MAIL_PASSWORD=your_mail_password \
  recipes-backend
```

Приложение будет доступно по адресу: `http://localhost:8080`

|   Метод    | Путь (v1)              | Описание                                         | Доступ                 |
